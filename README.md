# تره‌بار آنلاین — MVP UI

نسخه‌ی اولیه‌ی رابط کاربری اپ فروش آنلاین میوه و سبزی برای شاهرود، ساخته‌شده با Flutter.

## امکانات نمایشی این نسخه
- رابط کاربری مدرن و RTL
- صفحه خانه با بنر، دسته‌بندی، محصولات تازه و پرفروش
- جستجوی محصول
- سبد خرید و تغییر تعداد
- انتخاب بازه‌ی زمانی تحویل
- صفحه سفارش‌ها و وضعیت سفارش
- پروفایل مشتری با تعداد خرید و تاریخچه‌ی سفارش‌ها
- عدم نمایش مجموع مبلغ خرید مشتری در پروفایل
- ارتباط با مدیریت: ارسال پیام و تماس
- بخش اعلان‌ها

## مرحله بعدی اتصال واقعی
- ورود/ثبت‌نام با شماره موبایل و OTP
- Firebase/Supabase برای کاربران، محصولات و سفارش‌ها
- پنل مدیریت
- Firebase Cloud Messaging برای اعلان تغییر قیمت و سفارش
- ذخیره آدرس‌ها و زمان‌های تحویل
- پرداخت آنلاین
- ساخت APK انتشار برای اندروید
